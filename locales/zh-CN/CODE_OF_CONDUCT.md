# Contributor Covenant 行为准则

<a id="our-pledge"></a>

## 我们的承诺

我们是贡献者和维护者。我们希望营造开放、友好的环境。我们承诺，让每个人都能参与项目和社区而不受骚扰。无论年龄、体型、残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教、性身份或性取向如何，这项承诺都适用。

<a id="our-standards"></a>

## 我们的标准

以下行为有助于营造积极的环境：

- 使用友好、包容的语言。
- 尊重不同的观点和经历。
- 坦然接受建设性的批评。
- 关注对社区最有利的事。
- 对其他社区成员表现出同理心。

参与者的以下行为不可接受：

- 使用带有性意味的语言或图像。
- 不受欢迎的性关注或示好。
- 挑衅、侮辱或贬低性的评论，以及人身或政治攻击。
- 公开或私下骚扰。
- 未经明确许可，公布他人的私人信息。例如，实际地址或电子地址。
- 其他在专业环境中可被合理认定为不当的行为。

<a id="our-responsibilities"></a>

## 我们的责任

项目维护者必须阐明可接受行为的标准。当参与者有不可接受的行为时，维护者必须采取适当、公平的纠正措施。

项目维护者有权利和责任处理不符合本行为准则的贡献。他们可以删除、编辑或拒绝评论、commit、代码、wiki 编辑、Issue 和其他贡献。他们也可以因其他被认为不当、具有威胁性、冒犯性或有害的行为，暂时或永久封禁贡献者。

<a id="scope"></a>

## 适用范围

本行为准则适用于项目空间。当某人代表项目或社区时，它也适用于公共空间。代表项目或社区的例子包括：

- 使用项目的官方电子邮件地址。
- 使用官方社交媒体账号发帖。
- 在线上或线下活动中担任指定代表。

项目维护者可以定义并阐明什么情况属于代表项目。

<a id="enforcement"></a>

## 执行

要报告辱骂、骚扰或其他不可接受的行为，请通过 support@zoocode.dev 联系项目团队。项目团队会审查和调查所有投诉。项目团队会根据情况，采取其认为必要、适当的回应。项目团队必须对事件报告者的身份保密。项目团队可以另行发布具体执行政策的更多细节。

项目维护者必须本着善意遵守并执行行为准则。否则，他们可能受到暂时或永久的处理。项目领导团队的其他成员决定处理措施。
