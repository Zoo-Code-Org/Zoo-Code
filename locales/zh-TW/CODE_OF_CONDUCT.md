# Contributor Covenant 行為準則

<a id="our-pledge"></a>

## 我們的承諾

我們是貢獻者與維護者。我們希望營造開放、友善的環境。我們承諾，讓每個人都能參與專案與社群而不受騷擾。無論年齡、體型、身心障礙、族裔、性徵、性別認同與表達、經驗程度、教育程度、社經地位、國籍、外貌、種族、宗教、性身分或性傾向為何，這項承諾都適用。

<a id="our-standards"></a>

## 我們的標準

以下行為有助於營造正向的環境：

- 使用友善、包容的語言。
- 尊重不同的觀點與經驗。
- 坦然接受建設性的批評。
- 關注對社群最有利的事。
- 對其他社群成員展現同理心。

參與者的以下行為不可接受：

- 使用帶有性意味的語言或圖像。
- 不受歡迎的性關注或示好。
- 挑釁、侮辱或貶低性的留言，以及人身或政治攻擊。
- 公開或私下騷擾。
- 未經明確許可，公布他人的私人資訊。例如，實體地址或電子地址。
- 其他在專業環境中可被合理認定為不當的行為。

<a id="our-responsibilities"></a>

## 我們的責任

專案維護者必須說明可接受行為的標準。當參與者有不可接受的行為時，維護者必須採取適當、公平的改善措施。

專案維護者有權利與責任處理不符合本行為準則的貢獻。他們可以移除、編輯或拒絕留言、commit、程式碼、wiki 編輯、Issue 與其他貢獻。他們也可以因其他被認為不當、具有威脅性、冒犯性或有害的行為，暫時或永久封鎖貢獻者。

<a id="scope"></a>

## 適用範圍

本行為準則適用於專案空間。當某人代表專案或社群時，它也適用於公共空間。代表專案或社群的例子包括：

- 使用專案的官方電子郵件地址。
- 使用官方社群媒體帳號發文。
- 在線上或實體活動中擔任指定代表。

專案維護者可以定義並說明什麼情況屬於代表專案。

<a id="enforcement"></a>

## 執行

要回報辱罵、騷擾或其他不可接受的行為，請透過 support@zoocode.dev 聯絡專案團隊。專案團隊會審查與調查所有申訴。專案團隊會依情況，採取其認為必要、適當的回應。專案團隊必須對事件回報者的身分保密。專案團隊可以另行發布具體執行政策的更多細節。

專案維護者必須本於善意遵守並執行行為準則。否則，他們可能受到暫時或永久的處分。專案領導團隊的其他成員決定處分。
