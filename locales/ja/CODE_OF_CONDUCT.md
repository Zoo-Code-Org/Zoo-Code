# Contributor Covenant 行動規範

<a id="our-pledge"></a>

## 私たちの約束

私たちは貢献者とメンテナーだ。開かれた、歓迎される環境を目指している。誰もが嫌がらせを受けずにプロジェクトとコミュニティに参加できるようにすると約束する。年齢、体格、障害、民族、性的特徴、性自認と性表現、経験、教育、社会経済的状況、国籍、外見、人種、宗教、性的アイデンティティと性的指向に関係なく、この約束はすべての人に適用する。

<a id="our-standards"></a>

## 私たちの基準

次の行動は、よい環境を作る助けになる。

- 相手を歓迎し、誰も排除しない言葉を使う。
- 異なる考え方や経験を尊重する。
- 建設的な批判を素直に受け止める。
- コミュニティにとって最善のことに集中する。
- 他のコミュニティメンバーに共感を示す。

参加者による次の行動は認められない。

- 性的な言葉や画像の使用。
- 望まれない性的な関心や誘い。
- 荒らし、侮辱的または軽蔑的なコメント、個人攻撃や政治的な攻撃。
- 公の場や非公開の場での嫌がらせ。
- 本人の明確な許可なく、他人の個人情報を公開すること。住所や電子的な連絡先などが含まれる。
- 職業上の場で不適切だと合理的に判断できる、その他の行動。

<a id="our-responsibilities"></a>

## 私たちの責任

プロジェクトのメンテナーは、認められる行動の基準を明確にする必要がある。参加者が認められない行動を取った場合は、適切で公平な是正措置を取る必要がある。

メンテナーには、この行動規範に従わない貢献に対処する権利と責任がある。コメント、コミット、コード、wiki の編集、Issue、その他の貢献を削除、編集、拒否できる。不適切、脅迫的、攻撃的、有害だと判断したその他の行動に対しても、貢献者を一時的または永久に参加禁止にできる。

<a id="scope"></a>

## 適用範囲

この行動規範はプロジェクトの場に適用する。誰かがプロジェクトやコミュニティを代表する場合は、公の場にも適用する。代表としての行動には次の例がある。

- プロジェクトの公式メールアドレスを使う。
- 公式のソーシャルメディアアカウントで投稿する。
- オンラインや対面のイベントで、任命された代表として活動する。

メンテナーは、何がプロジェクトを代表する行動なのかを定義し、明確にできる。

<a id="enforcement"></a>

## 規範の実施

攻撃的な行動、嫌がらせ、その他の認められない行動を報告するには、support@zoocode.dev でプロジェクトチームに連絡しよう。チームはすべての苦情を確認し、調査する。状況に応じて必要かつ適切だと判断する対応を取る。チームは、出来事を報告した人の身元を秘密にする必要がある。具体的な実施方針の詳細は、別途公開することがある。

メンテナーは、誠実に行動規範を守り、実施する必要がある。守らない場合、一時的または永久的な措置を受けることがある。他のプロジェクト指導部のメンバーが措置を決める。
