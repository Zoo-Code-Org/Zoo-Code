An invoke block is the mechanism used to call a tool. It's written as an XML-like structure containing a function invocation with named parameters. Here's a literal example, written as plain text:

```xml
<invoke name="read_file">
<parameter name="path">src/example.txt</parameter>
</invoke>
```

The structure works like this:

- An outer `invoke` tag carries a `name` attribute identifying which tool to call (here, `read_file`).
- Inside it, one or more `parameter` tags each carry a `name` attribute identifying the argument (here, `path`).
- The value of each parameter goes between the opening and closing `parameter` tags (here, `src/example.txt`).

For string and scalar parameters, the value is written as-is between the tags. For lists or objects, the value would be formatted as JSON instead.
