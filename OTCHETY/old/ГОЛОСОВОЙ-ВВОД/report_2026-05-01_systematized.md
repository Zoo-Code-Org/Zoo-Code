## 2. Анализ по критериям

### 2.1. Строго In-Memory (Zero-Disk)

Все представленные библиотеки поддерживают обработку в памяти.

- **Лидеры**: `nnnoiseless` (поддержка `from_static_bytes` для модели 60KB), `TEN VAD`, `Rustpotter`.

### 2.2. Вес ядра < 500KB

- **Проходят**: `cpal` + `nnnoiseless` (суммарно ~310KB с учетом накладных расходов), `TEN VAD` (306KB), `Rustpotter` (до 500KB).
- **Не проходят**: `DeepFilterNet3` (>1MB), `WebRTC` (>1MB), `Porcupine` (>1MB).

### 2.3. Супер-фильтрация (VAD + Noise Suppression)

1. **Качество**: `DeepFilterNet3` (10) > `nnnoiseless` (9) > `WebRTC` (8).
2. **Вес/Качество**: `nnnoiseless` — золотая середина. `TEN VAD` отлично справляется с детекцией речи при малом весе.

### 2.4. Wake Word поддержка

- **Rustpotter**: Единственный полноценный open-source вариант на Rust, вписывающийся в весовые рамки.
- **Porcupine**: Качество выше, но вес и лицензия исключают его из "легкого" стека.

## 3. Рекомендуемые связки (Стек технологий)

### Вариант А: "Золотая середина" (Рекомендуемый)

- **Audio I/O**: `cpal`
- **Noise Suppression**: `nnnoiseless` (RNNoise, модель 60KB)
- **VAD**: Встроенный в `nnnoiseless` (`vad_prob`) + опционально `TEN VAD` (если позволяет бюджет памяти).
- **Wake Word**: `Rustpotter`
- **Итоговый вес**: ~450-500KB (предел ядра).
- **Плюсы**: Rust-native, In-Memory, отличное качество шумоподавления.

### Вариант Б: "Ультралайт" (Минимум ресурсов)

- **Audio I/O**: `cpal`
- **Noise Suppression**: `Speex DSP` (или только RMS-пороги).
- **VAD**: RMS (кастомный).
- **Wake Word**: `Rustpotter` (tiny модели).
- **Итоговый вес**: < 300KB.
- **Минусы**: Низкое качество очистки звука.

### Вариант В: "Максимальное качество" (Если лимит 500KB не критичен)

- **Audio I/O**: `cpal`
- **Noise Suppression**: `DeepFilterNet3`
- **VAD**: `TEN VAD`
- **Wake Word**: `Rustpotter`
- **Итоговый вес**: > 1.5MB.
- **Плюсы**: Лучшее качество STT за счет чистоты аудио.

---

## 4. Итоговый вывод

Для реализации гибридного голосового модуля RooCode с ядром **< 500KB** и режимом **In-Memory**, лидирует связка:

**`cpal` + `nnnoiseless` + `Rustpotter`**

**Почему:**

1. **Вес**: `nnnoiseless` (~160KB) + `cpal` (~150KB) + `Rustpotter` (~200KB) укладываются в лимит 500KB.
2. **Качество**: Нейросетевое шумоподавление (RNNoise) дает 9/10 при малом весе.
3. **Интеграция**: Все компоненты Rust-native, поддерживают статическую линковку и загрузку моделей из памяти (`include_bytes!`).

_Примечание: TEN VAD (306KB) лучше по качеству VAD, чем встроенный в RNNoise, но его добавление вплотную приближает ядро к лимиту 500KB. Рекомендуется начать с `nnnoiseless` как VAD/NS комбо._
