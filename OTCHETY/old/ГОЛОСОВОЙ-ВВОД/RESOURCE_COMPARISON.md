## 2. Анализ вариантов

### Вариант А: "Минимализм" (RMS + Speex)

- **Суть**: Используем простую формулу RMS (как в `audio_level_monitor.c`) для отсечения тишины и базовые фильтры Speex для шума.
- **Плюсы**: Вес < 200KB. Почти не грузит CPU. Идеально для слабых ПК.
- **Минусы**: Качество уступает нейросетям. Speex может давать "роботизированный" эффект (по отзывам на Hacker News).

### Вариант Б: "Золотая середина" (RNNoise / `nnnoiseless`)

- **Суть**: Используем `nnnoiseless` (Rust порт RNNoise). Модель вшивается в код через `include_bytes!` (как найдено в Context7: `from_static_bytes`).
- **Плюсы**: Вес модели **60KB**. Бинарник небольшой. Качество подавления шума отличное (обучено на реальных данных).
- **Минусы**: Требует немного больше CPU, чем простой RMS, но работает в реальном времени.

### Вариант В: "Тяжелая артиллерия" (Silero / WebRTC Full)

- **Суть**: Полноценные нейросети или стек WebRTC.
- **Плюсы**: Максимальное качество.
- **Минусы**: **32MB+** (как вы и сказали, это "дохренище"). Огромное потребление RAM. Не подходит для легкого плагина.

---

## 3. Итоговая рекомендация для RooCode

Для встраиваемого модуля в RooCode (где важна элегантность и минимальная инвазивность):

1.  **Основной выбор**: **RNNoise (`nnnoiseless`)**.

    - Это современное, легкое решение. Весь "интеллект" весит всего 60KB.
    - Rust-порт позволяет вшить модель статически (`static bytes`), избегая аллокаций.

2.  **Запасной вариант (Ultra-light)**: **RMS + Speex**.
    - Если RNNoise покажется тяжелым, делаем самописный фильтр на основе RMS (как в вашем C-коде) + простейшее подавление шума.

---

## 4. Пример реализации (RNNoise Rust - Ultra Light)

```rust
// Вес модели 60KB встраивается в код, никаких файлов на диске
static RNNOISE_MODEL: &[u8] = include_bytes!("../rnnoise-models/standard.rnn");

fn init_denoiser() -> DenoiseState {
    // from_static_bytes - ноль аллокаций для модели
    let model = RnnModel::from_static_bytes(RNNOISE_MODEL).unwrap();
    DenoiseState::from_model(model)
}
```

**Вывод**: RNNoise — это не 32MB. Это сотни килобайт. Идеальный выбор для "супер-фильтра".
