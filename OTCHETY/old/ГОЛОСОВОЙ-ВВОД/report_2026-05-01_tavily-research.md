**Дата:** 2026-05-01  
**Цель:** Поиск легковесных альтернатив (Core < 500KB, In-Memory, Rust Audio Core) для VAD, шумоподавления и Wake Word.

## Детальный анализ

### 1. VAD (Voice Activity Detection)

- **TEN VAD**: Наиболее подходящая замена Silero. Вес < 500KB для Linux, высокая точность, низкое потребление CPU. Поддерживает обработку в памяти (In-Memory).

### 2. Аудио I/O (Input/Output)

- **Tinyaudio**: Рекомендуется как более легковесная замена CPAL. Предоставляет упрощенный API и гарантированный размер буфера, что важно для стриминга.
- **CPAL**: Стандарт де-факто для Rust, но избыточен по сложности для простых задач.

### 3. Wake Word (Ключевое слово)

- **Rustpotter**: Идеально для Rust-проектов. Open-source, позволяет обучать свои модели. Низкое потребление ресурсов.
- **Porcupine**: Если бюджет позволяет коммерческую лицензию, это лучший выбор по качеству.

### 4. Шумоподавление (Noise Suppression)

- **DeepFilterNet3**: Значительно превосходит RNNoise по качеству (PESQ/STOI), но требует больше ресурсов.
- **RNNoise**: Если критичен размер (< 100KB) и CPU, RNNoise остается отличным выбором.

## Итоговые рекомендации

1. **VAD**: Использовать **TEN VAD** (легкий, точный, In-Memory).
2. **Audio I/O**: Переход на **Tinyaudio** для упрощения кода и снижения накладных расходов.
3. **Wake Word**: Внедрение **Rustpotter** (бесплатно, Rust-native).
4. **Noise Suppression**: **DeepFilterNet3** для качества, либо оставить **RNNoise** для экономии ресурсов.
